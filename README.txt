KALIMBA.DREAMS — STUDIO EDITION

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html.
3. Klik tuts kalimba atau gunakan keyboard komputer.
4. Pilih lagu pada Song Library.
5. Ikuti rumus nada di panel Lesson, lalu tekan Play selected song.

Audio menggunakan Web Audio API, jadi tidak perlu file MP3.
Klik tuts pertama kali jika browser menunggu izin audio.
